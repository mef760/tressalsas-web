# Tres Salsas — web

3 tacos. 3 salsas. Hechos en casa.

Sitio estático (HTML/CSS/JS, sin build). Publicado con GitHub Pages desde `main`.

## Editar datos
Todo lo configurable está en el bloque `CONFIG` al inicio del `<script>` de `index.html`:
- `whatsapp`: número para los pedidos (formato wa.me, solo dígitos)
- `pedidosya`: link al local en PedidosYa
- precios (`precioSuelto`, `precioOrden3`, `precioSalsaExtra`), horario, tacos y salsas

Cada push a `main` actualiza el sitio.
